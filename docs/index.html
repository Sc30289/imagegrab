产品介绍

做电商图，最费时间的其实是「存图」

详情页里的图片分散在轮播、详情长图、SKU 缩略图里，还大量使用懒加载与背景图。 右键另存为，一张一张点，格式还不统一——这是绝大多数运营、美工、选品同学的日常。

图片分散，找不全

主图和详情图分属不同模块，懒加载的图片不滚动就根本不加载，肉眼很难确认到底有没有漏。

无法批量保存

浏览器原生只支持单张另存，几十张图要重复几十次「右键 → 另存为」，还容易存错文件。

格式不统一

同一页面里 jpg、png、webp、avif 混着来，导入设计软件或上架后台时还要再转换一次。

图提取把这三件事合成一步：点击按钮 → 自动扫描 → 勾选 → 批量下载为 PNG。 所有处理都在你自己的浏览器里完成，图片不会上传到任何服务器。

核心功能

六个细节，把「存图」这件事做干净

从扫描、过滤、预览到下载，每一步都为电商详情页的真实结构做了适配。

一键提取

自动扫描页面所有商品图，兼容 <img>、srcset、data-src 等懒加载写法与背景图。

智能过滤

自动排除图标、logo、占位图与 1×1 像素图，小于 100×100 的图片不会出现在结果里。

集中预览

新标签页里网格化展示全部图片，标注原始尺寸，点「原图」可单独查看。

自由勾选

全选、反选、单张勾选都支持，实时显示「已选 N / 共 M 张」，只下需要的那几张。

统一 PNG

jpg / webp / avif 一律通过 canvas 转成 PNG，透明背景不丢，导入设计软件不再踩坑。

批量下载

一键保存到浏览器默认下载目录，文件名按「商品图_001.png」自动补零编号，带进度与结果反馈。

安装步骤

四步装好，不折腾

图提取以「开发者模式加载已解压扩展」的方式安装，全程不到一分钟。

  1. 01

    下载并解压

    下载插件压缩包，解压到本地任意文件夹（路径建议用纯英文，避免中文路径出问题）。

  2. 02

    打开扩展管理页

    在 Chrome 地址栏输入 chrome://extensions 并回车。

  3. 03

    开启开发者模式

    打开页面右上角的「开发者模式」开关，顶部会出现「加载已解压的扩展程序」按钮。

  4. 04

    加载插件文件夹

    点击「加载已解压的扩展程序」，选择第一步解压出来的文件夹，图标出现在工具栏即安装成功。

使用方式：打开任意商品详情页，页面右下角会出现「获取图片」按钮； 点击后在新的预览标签页里勾选图片，点「下载选中」，图片会保存为 PNG 到浏览器默认下载目录。
